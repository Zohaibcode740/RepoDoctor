# RepoDoctor

RepoDoctor is a developer tool that analyzes software repositories and generates a health score based on documentation, testing, dependencies, security, licensing, CI/CD, and repository configuration.

## Features

- README quality checks
- License detection
- Test configuration detection
- `.gitignore` security checks
- GitHub Actions detection
- Documentation link checking
- Dependency update detection
- Secret detection
- Local repository scanning
- GitHub repository scanning
- JSON output for automation
- JSON report generation
